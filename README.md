Retail Customer Analytics Pipeline

Производственный пайплайн для RFM-анализа клиентов интернет-магазина. Автоматизированная система обработки данных, сегментации клиентов и визуализации результатов.

## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone <repository-url>
cd retail_customer_analytics

# 2. Запустить все сервисы
docker-compose up -d

# 3. Проверить статус
docker-compose ps
